Iniciar Backend:

Apartamento: (revisar siempre dirección IP)

cd /d d:\Documentos\espacio_vc\app_fink\backend
set PORT=4002
set CORS_ORIGIN=http://localhost:3000,http://127.0.0.1:3000,http://192.168.1.104:3000
echo Starting backend on port %PORT% with CORS_ORIGIN=%CORS_ORIGIN%
